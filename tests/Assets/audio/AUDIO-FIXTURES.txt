tests/Assets/audio - generated audio test fixtures
==============================================================================

These files are NOT third-party audio. Every one is synthesized (sine tones,
a frequency sweep, seeded noise, digital silence) and encoded locally by
tools/make_test_fixtures/make_fixtures.sh. Re-run that script to regenerate them.

Generated by : tools/make_test_fixtures/make_fixtures.sh
Encoder      : ffmpeg version 7.1.5-0+deb13u1 Copyright (c) 2000-2026 the FFmpeg developers

WHAT EACH FIXTURE IS FOR
------------------------------------------------------------------------------
  vorbis-tone-mono-22050.ogg          low-rate mono, the game-SFX shape
  vorbis-tone-stereo-44100.ogg        everyday stereo; also the native build
                                      harness's decode smoke test input
  vorbis-sweep-stereo-48000.ogg       2 s sweep 200 Hz -> 2 kHz; the instantaneous
                                      frequency identifies the position, so seeks
                                      can be verified from the audio itself
  vorbis-truncated.ogg                truncated stream; must fail cleanly
  flac-*.flac                         one per decoder path (see the table below);
                                      each ships with the .wav it was encoded from,
                                      and a correct decoder reproduces that PCM
                                      sample for sample, because FLAC is lossless
  flac-truncated.flac                 truncated stream; must fail cleanly
  opus-tone-mono-from-16000.opus      METADATA fixture (this library does not decode
                                      Opus). Encoded from 16 kHz, so OpusHead declares
                                      16000 while the stream decodes at 48000 - the
                                      voice-note shape, and the case that catches a
                                      reader reporting the declared rate as the real one
  opus-tone-stereo-48000.opus         the everyday Opus case; with the mono file it
                                      pins the pre-skip subtraction in the duration

  flac-tone-mono-16bit-22050          fixed predictors only, independent channels
  flac-tone-stereo-16bit-44100-*side  the four stereo decorrelation modes
  flac-noise-stereo-16bit-44100       verbatim subframes / wide Rice parameters
  flac-silence-stereo-16bit-44100     constant subframes
  flac-tone-stereo-24bit-48000        24-bit sample path
  flac-*-oddlength                    short final block

NOTE: ffmpeg does not write a SEEKTABLE metadata block, so these fixtures exercise
the reader's frame-search seek path. The SEEKTABLE path is covered by a test that
splices a synthetic SEEKTABLE into one of these files at run time.

NOTE: the .opus fixtures both carry a pre-skip of 312 and a final granule position of
12312, so their true playable length is (12312 - 312) / 48000 = exactly 0.25 s. Their
CONTAINER duration reads 0.2565 s - ffprobe reports that too - because the granule
counts the priming samples; the numbers are pinned in the tests for that reason.

NOTE ON REGENERATION: an Ogg muxer picks a RANDOM stream serial number per run, so
re-running make_fixtures.sh always produces different .ogg and .opus bytes even on the
same ffmpeg build. The SHA256s below identify the committed files; they are not a
reproducibility check for those two formats. The .flac and .wav files do reproduce
byte-identically.
