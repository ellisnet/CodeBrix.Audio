================================================================================
BUILD-PROVENANCE - what produced each shipped codebrix_miniaudio binary
================================================================================

One record per binary under
src/CodeBrix.Audio.Engine/Backends/MiniAudio/runtimes/<rid>/native/.

Update this file whenever a binary is replaced. The per-build details it is
copied from are written by the build scripts to
tools/build_native_libraries/output/<rid>/build-info.txt.

All binaries are built from the sources vendored in this folder - miniaudio and
stb_vorbis are in-tree, and no build step reaches outside the repository or
downloads source. See tools/build_native_libraries/README.txt for how to
reproduce any of them, and ../../THIRD-PARTY-NOTICES.txt for licensing.

  Notes on the macOS pair, both from one build.sh run on one machine:

  * MINIMUM macOS IS PINNED, and is the exact analogue of the glibc ceiling on
    Linux. Left unset, clang stamps the BUILD HOST's OS version into the Mach-O
    load command and dyld then refuses the dylib on any older system - a binary
    built on this macOS 26 host would have demanded macOS 26. The floors live in
    tools/build_native_libraries/pins.env (MACOS_MIN_ARM64 / MACOS_MIN_X64) and
    the build verifies the file actually carries them.

  * BOTH ARE AD-HOC SIGNED by an explicit codesign step in build.sh. Do not
    assume the toolchain does it: Apple's linker auto-signs arm64 output but
    leaves x86_64 unsigned, and the CODE_SIGN_* properties in CMakeLists.txt
    apply to CMake's Xcode generator only, which is not the generator used here.

  * WHAT THEY REPLACED: SoundFlow v1.4.1's prebuilt miniaudio binaries, renamed
    to codebrix_miniaudio.dylib. Those were built without stb_vorbis and so could
    not decode Ogg Vorbis natively - .ogg on macOS fell back to the managed
    Vorbis decoder in CodeBrix.Audio. These binaries export sf_has_vorbis() and
    ma_stbvorbis_*, so macOS now uses the native path like every other RID.
