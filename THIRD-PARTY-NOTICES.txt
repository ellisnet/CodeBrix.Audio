The CodeBrix.Audio.MitLicenseForever NuGet package ships two assemblies:

  * CodeBrix.Audio        — a fully managed, cross-platform audio FILE library
                            (WAV/MP3/Ogg Vorbis/FLAC reading, Standard MIDI File
                            read/write, MP3 ID3v2 and Vorbis-comment tags, DSP
                            primitives, SoundFont/MIDI synthesis). Contains no
                            native code. Adapted from NAudio, NLayer, NVorbis and
                            MeltySynth (entries 1-2, 5 and 7); its FLAC decoder is
                            original CodeBrix code written from the format
                            specification and is not third-party.
  * CodeBrix.Audio.Engine — a cross-platform audio ENGINE (playback, recording,
                            effects, editing/mixing, MIDI, synthesis,
                            visualization) with a bundled native miniaudio
                            backend for Windows, macOS, and Linux. Vendored from
                            SoundFlow, miniaudio and stb_vorbis (entries 3-4
                            and 6).

Incorporated source (production):

      hierarchy, and MidiEventCollection (NAudio.Midi/*).

    test helpers adapted from the NAudio.Core.Tests project (MIT). They were
    converted from NUnit to xUnit v3 + SilverAssertions and re-namespaced to

Modifications made during the port:
    - Namespaces renamed from NAudio.* to CodeBrix.Audio.* (see provenance
      comments on each file's namespace line).

      NAudio.Wasapi, NAudio.Asio, NAudio.Dmo, NAudio.Alsa, NAudio.WinForms,

      settings were kept as-is (nullable reference types enabled, implicit usings,

      win-x64, win-arm64, linux-x64, linux-arm64, linux-riscv64, osx-x64,
      osx-arm64.
    - library.c additionally compiles stb_vorbis into the same translation unit,
      which is what gives the native backend an Ogg Vorbis decoder (entry 6), and
      exports sf_has_vorbis() so managed code can tell whether a given binary has
      one.

Native binaries currently shipped:
    The Linux binaries (linux-x64, linux-arm64, linux-riscv64) are built from the
    sources in native/miniaudio by tools/build_native_libraries; see
    native/miniaudio/BUILD-PROVENANCE.txt for exactly what produced each one. The
    Windows and macOS binaries are still SoundFlow v1.4.1's own prebuilt

    NVorbis's entire decoder library (its NVorbis project: the Ogg container

      than modified: seeking into the middle of a Vorbis packet leaves the
      decoder without the preceding packet's overlap history, so up to one block
      of audio after a seek can differ from a sequential decode of the same
      region before the two converge. See the remarks on OggVorbisFileReader.
